# ZANOZA — прототип сайта

Концепт редизайна сайта стриптиз-клуба Zanoza (Москва): первый экран с видео, блок-история на скролле, акции клуба, полноэкранное меню.

## Структура

```
index.html          — вся страница (разметка, стили, скрипты)
assets/video/       — фоновое видео первого экрана
assets/img/         — фото для карточек, меню и фона
assets/fonts/       — Bad Russian, Inter Tight, Manrope, Cormorant Garamond
assets/js/          — Lenis (плавный скролл)
```

## Запуск локально

Открыть `index.html` в браузере или поднять сервер:

```
npx serve .
```

## Публикация на GitHub Pages

Settings → Pages → Source: `Deploy from a branch` → `main` / `root`.
